Overview

项目概览

DE2Extra 是一个基于开源 NEORV32 RISC-V 处理器核的完整 SoC 系统，运行在 Altera DE2-115 FPGA 上。围绕开源 CPU 核心自研了 10 个活跃 Wishbone 外设 IP、SoC 互联、FreeRTOS 固件及 22 个命令行应用——从 RTL 到 C 代码的全栈工程实践。

软件栈 — FreeRTOS + Shell

  • 4 任务: uart_input / shell / active / status
  • PS/2 键盘主输入 + UART 双路接收
  • SDRAM 执行 @ 0x01000000 (~207KB 固件)

  • 因资源占用暂时从综合中移除
Lessons

挑战与收获

踩过的坑

  • SDRAM 相位偏移: DRAM_CLK 需要 +1.56ns 相移
  • XBUS 协议: 组合逻辑 ack 与寄存器级不兼容
  • 跨时钟域: VGA 25MHz / SDRAM 100MHz / CPU 50MHz
  • IMEM 64KB MIF: 原始 VHDL 常量数组导致 OOM
  • WM8731 I2C: 7-bit 地址 + 寄存器地址字节混淆

关键收获

  • 全栈 SoC 设计: 从 RTL 到固件到应用
  • Wishbone 总线协议实战: 地址解码、burst、CDC
  • FreeRTOS 在资源受限环境的实践
  • VHDL-2008 与 Quartus 综合约束
  • 增量开发 + 持续上板验证的工作流
