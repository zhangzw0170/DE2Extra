# 编译烧录下载

## 一条龙脚本（推荐）

```bash
# 日常改软件（C 代码）—— 编译 + 上传
./run/deploy_de2shell_rtos.sh app

# 改了 bootloader / RTL —— 编译 bootloader + Quartus 综合 + 烧录 SOF
./run/deploy_de2shell_rtos.sh fpga

# 全量：fpga + 编译 app + 上传
./run/deploy_de2shell_rtos.sh full

# 仅上传当前 bin（不编译）
./run/deploy_de2os.py --wait
```

注意：从 Git Bash 运行（PowerShell 里 bash 会落到 WSL）。

## 手动分步

### 日常：改了软件（C 代码）

```bash
# 1. 编译（Docker，~25 秒）
docker run --rm -v "E:/Main/JuniorII/NonExam/FPGA/DE2Extra:/work" de2extra-builder bash -c \
  "cd /work && mkdir -p sw/app/de2shell_rtos/build && make -C sw/app/de2shell_rtos all image NEORV32_HOME=/work/neorv32"

# 2. 上传（Python，~5 秒，板子需要在上电 bootloader 状态）
#    如果板子已在运行固件，加 --wait 自动软重启进入 bootloader
python run/upload_de2os.py --wait
#    如果板子刚烧录 SOF 或刚按 KEY0，bootloader 正在等待，不加 --wait：
python run/upload_de2os.py
```

就这两步。完事。

### 改了 RTL（VHDL）或 bootloader

用一条龙的 `./run/deploy_de2shell_rtos.sh fpga` 或 `full`。

## 产物路径

| 产物 | 路径 |
|------|------|
| FPGA bitstream | `par/de2os/de2os.sof` |
| 固件 binary (bootloader 上传用) | `sw/app/de2shell_rtos/neorv32_exe.bin` |

## 环境

| 项目 | 值 |
|------|-----|
| Quartus | 23.1std Lite |
| Docker image | `de2extra-builder`（riscv-none-elf-gcc 14.3.0） |
| 串口 | COM10, 115200 8N1 |
| 板子 | DE2-115, USB-Blaster JTAG |

## 注意事项

- 板子需要处于 bootloader 状态才能上传（上电或按 KEY0）
- bootloader 不清 VGA，VGA 画面残留是正常的，看串口即可
- KEY0 只复位，不会自动下载新固件
- `make clean && make all` 要分开跑，否则 `build/` 目录会被删后不重建
- Pin 分配必须对照 `DE2-115引脚表.xlsx`
