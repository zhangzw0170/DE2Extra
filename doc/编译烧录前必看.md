# 编译烧录下载

## CLI 工具（推荐，跨平台）

```bash
python run/de2extra.py sw-build      # 编译固件（Docker 交叉编译）
python run/de2extra.py sw-upload     # 上传固件（UART, 自动软重启进 bootloader）
python run/de2extra.py hw-build      # Quartus 综合（含 bootloader 重编）
python run/de2extra.py hw-flash      # JTAG 烧录 SOF
```

### 环境自动检测

| 项目 | 检测方式 | 手动覆盖 |
|------|----------|----------|
| 串口 | 自动扫描 | `--port COM3` 或 `DE2OS_COM` 环境变量 |
| Quartus | 搜索标准安装路径 + PATH | `QUARTUS_ROOTDIR` 环境变量 |
| Docker | PATH 搜索 | 需要安装 Docker Desktop |

### 典型工作流

```bash
# 日常改软件（C 代码）—— 两步
python run/de2extra.py sw-build && python run/de2extra.py sw-upload

# 改了 RTL / bootloader —— 三步
python run/de2extra.py hw-build && python run/de2extra.py hw-flash && python run/de2extra.py sw-upload
```

### 编译耗时（参考）

| 步骤 | 耗时 | 条件 |
|------|------|------|
| sw-build | ~25s | Docker 已启动 |
| sw-upload | ~20s | 含软重启 + SDRAM self-test |
| hw-build | ~15min | bootloader + Quartus 综合 |
| hw-flash | ~11s | JTAG 烧录 |

## 旧脚本（仅本机 Git Bash）

> 以下脚本仍可用，但仅限 Windows Git Bash 环境。跨平台请用上面的 `de2extra.py`。

```bash
./run/deploy_de2shell_rtos.sh app     # 编译 + 上传
./run/deploy_de2shell_rtos.sh fpga    # bootloader + Quartus + 烧录
./run/deploy_de2shell_rtos.sh full    # 全量
```

必须从 **Git Bash** 运行（PowerShell / CMD 里 `bash` 会落到 WSL）。

## 产物路径

| 产物 | 路径 |
|------|------|
| FPGA bitstream | `par/de2os/de2os.sof` |
| 固件 binary (bootloader 上传用) | `sw/app/de2shell_rtos/neorv32_exe.bin` |

## 环境

| 项目 | 值 |
|------|-----|
| Quartus | 23.1std Lite |
| Docker image | `de2extra-builder`（riscv-none-elf-gcc 14.3.0） |
| Python 依赖 | `pyserial`（`pip install pyserial`） |
| 串口 | 自动检测, 115200 8N1 |
| 板子 | DE2-115, USB-Blaster JTAG |

## 注意事项

- `sw-upload` 自动发软重启命令让固件回到 bootloader，无需按 KEY0
- bootloader 不清 VGA，VGA 画面残留是正常的，看串口即可
- KEY0 只复位，不会自动下载新固件
- `make clean && make all` 要分开跑，否则 `build/` 目录会被删后不重建
- Pin 分配必须对照 `DE2-115引脚表.xlsx`
